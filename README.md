# Hisab Kitab

Personal money and editing-business ledger.

- `index.html`: the web app (personal + editing books, budgets, pending client payments, CSV/JSON backup).
- `Hisab-Kitab.xlsx`: Excel version with three sheets: Personal, Editing, Overview. Type entries in Personal and Editing; Overview calculates month-wise totals for the financial year (April to March) by formula.
